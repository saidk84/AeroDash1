# AeroDash V02 — Unity 3D Android-first prototype

A minimal playable flying-car delivery prototype for Unity 3D.

## Quick start
1. Create a **Unity 6** 3D project (Built-in Render Pipeline) in a local directory.
2. Copy the contents of this V02 folder into the Unity project root (Assets and ProjectSettings).
3. Open Unity and press Play in any empty scene. The bootstrap script generates the world at runtime.
4. Controls: WASD / arrow keys to move, Space to rise, Left Shift to descend. On Android, use the on-screen controls.
5. Fly to the yellow pickup marker, then the green delivery marker to earn 100 coins.

## Android
Install Unity Android Build Support (SDK/NDK/OpenJDK) using Unity Hub. In Build Profiles select Android, switch platform, and build an APK. A real APK has **not yet been built or tested**.

## Scope
This prototype uses primitive geometry and is not yet a realistic Dubai map. No third-party assets, in-app purchases, or accounts are included. V01 remains untouched.
